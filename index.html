02 / PERSONAL PROJECT

継続開発中In active development

基礎知識Web版

イベント運営の情報を、
ひとつの場所に。 One place for everything
an event team needs.

基礎知識Web版は、イベントスタッフが必要な情報へ迷わずアクセスできるようにするWebポータルです。会期ごとのタイムテーブル、部屋割り、企画、販売物、お知らせを一元化し、カテゴリを横断した検索にも対応しています。 基礎知識Web版 is a web portal that helps event staff find the information they need without friction. It brings schedules, room assignments, programs, merchandise, and announcements together for each event, with search across every category.

個人開発として、フロントエンドからAPI、認証、データベース、Cloudflare上のインフラまで、プロダクト全体の設計・実装・改善を続けています。 As a personal project, I continue to design, implement, and improve the product end to end—from the frontend and API to authentication, database, and Cloudflare infrastructure.
